## 用户目标与阶段

用户希望控制带音响的外接显示器音量，尤其是系统音量键无法调节的 HDMI/DisplayPort 输出。已完成技术验证、菜单栏原型、滑块修复、自动恢复和媒体键/HUD。用户决定以音桥（VolumeBridge）长期维护，放在 `<project-root>`，使用 Git，并要求本地化与完整 Agent 交接。

目前阶段是本机可用原型转为长期项目，尚未进入公开发布。仓库不依赖共享聊天链接才能继续开发；历史原型源码仍保留，但本仓库是后续唯一源码入口。
